## Files and accurate labels
- logos/*dimensional*: transparent luminous full-color symbol or symbol with gold wordmark. PNGs have genuine alpha transparency.
- logos/*ivory* and *navy*: monochrome alternate silhouettes, for reproduction/contrast only. The dimensional treatment is primary.
- icons/png: dimensional icon with navy tile and transparent exterior corners. Not a transparent gold-only symbol.
- icons/windows/optimadhan.ico: embedded 16,20,24,32,40,48,64,128,256 px frames.
- icons/tray: intentionally simplified crescent, because architectural detail and glow cannot be clear at 16 px. Light means light artwork on a dark taskbar; dark means dark artwork on a light taskbar. Gold is an optional accent, not a status indicator. ICO frames: 16,20,24,32,40,48,64 px.
- source: generated raster masters and editable tray SVG geometry. The dimensional logo is raster artwork; no editable vector version is claimed.
- references: supplied master, moodboard, application/widget concept and splash concept. These are artwork, not running software.

## Color and typography
UI midnight #07142D, elevated surface #112644, gold accent #FFD65A, ivory #F6F1E7, muted #ADBAD0. These are UI design tokens, not a claim that every gradient pixel matches one hex value. Use ivory body text on navy; use navy text on light surfaces. Validate final UI contrast. Segoe UI Regular and Bold, with Windows system fallback. Wordmarks in PNG are rendered; no font installation is needed and no font binaries are bundled.

## Usage
Keep aspect ratio and at least 1/8 of the symbol canvas width as clear space. Prefer horizontal logo >=280 px, stacked >=220 px and dimensional symbol >=64 px. Small application ICO frames exist for shell compatibility; use tray variants for notification area. Never stretch, flatten the primary artwork, add calligraphy, add stars or recolor the full-color master. Keep UI panels restrained so the luminous identity remains the focal point. Suggested body 14–16 logical px, section titles 20–24, countdown 32–40; spacing rhythm 8 px; panel radii 12–16 px.

## Implementation and accuracy
Use supplied assets rather than redraw. Switch tray contrast variants for actual taskbar appearance and high contrast settings. Verify shell appearance at 100%,125%,150%,200% scaling. File integrity, alpha and embedded frame sizes are checked; live Windows shell integration is not tested by this kit.
UI concepts deliberately show no prayer times. Obtain schedules from validated location/date/time zone/calculation method/Asr settings and adjustments. Keep widget, background scheduler and main window consistent, disclose offline freshness, and handle daylight saving. Sunrise is informational, not one of the five prayers. Sehri/Imsak policy must be explicit; do not automatically equate it with Fajr. Branding changes must not replace or weaken the existing location-aware calculation/API flow.
